# เครื่องมือลบแอปโฆษณา & มัลแวร์ Android (สำหรับหน้าร้านซ่อมมือถือ)

เครื่องมือ Desktop (Windows / Mac / Linux) สำหรับ **ช่างซ่อมมือถือใช้เองหลังเคาน์เตอร์** เพื่อสแกน วิเคราะห์ความเสี่ยง และลบแอปโฆษณา/มัลแวร์ออกจากเครื่องลูกค้าผ่านสาย ADB อย่างรวดเร็ว หมุนคิวลูกค้าได้ทันที ปลอดภัย 100% ไม่มีโหมดลบอัตโนมัติ ทุกขั้นตอนต้องผ่านการยืนยันจากช่าง

---

## จุดเด่นและฟังก์ชันหลัก

1. **Pipeline การทำงาน 4 ขั้นตอน:**
   - **สแกน:** ค้นหาเฉพาะแอป Third-party ด้วยคำสั่ง `adb shell pm list packages -3 -i` (ไม่มีทางแตะต้องแอประบบ `-s`)
   - **วิเคราะห์:** ตรวจสอบ Installer และ Permissions เสี่ยง (`SYSTEM_ALERT_WINDOW`, `BIND_ACCESSIBILITY_SERVICE`, `BIND_DEVICE_ADMIN`, `REQUEST_INSTALL_PACKAGES`) พร้อมรองรับ Custom/OEM Permissions (Samsung, Xiaomi, Oppo)
   - **แสดงผล:** แสดงไอคอนแอป (ดึงจาก APK พร้อมระบบ Fallback สีคมชัด), ชื่อแอป, Package ID, ป้ายระดับความเสี่ยง (แดง = น่าสงสัยมาก, เหลือง = น่าสงสัย, เขียว = ปลอดภัย) พร้อมเรียงความเสี่ยงสูงไว้ด้านบนสุด
   - **ลบอย่างปลอดภัย:** แยกปุ่ม 2 จังหวะเสมอ — **"ถอนสิทธิ์ Device Admin"** ก่อน แล้วค่อย **"ลบแอปที่เลือก"** (พร้อมหน้าต่าง Confirm ยืนยันรายการแอปเสมอ)

2. **ระบบเตือนเครื่องซ้ำใน 30 วัน (30-Day Repeat Alert):**
   - บันทึกประวัติเครื่องลง SQLite (`data/repair_shop.db`)
   - เมื่อเสียบเครื่องที่เคยเข้ามารับบริการภายใน 30 วัน ระบบจะแสดงแถบเตือนสีส้มทันที เพื่อให้ช่างแนะนำการป้องกันหรือแพ็กเกจดูแลพิเศษแก่ลูกค้า

3. **Shop Threat Intelligence (ปัญญาประดิษฐ์ฐานข้อมูลประจำร้าน):**
   - เรียนรู้จากประวัติการลบจริงในร้าน หากแอปใดถูกตรวจพบและลบข้ามเครื่องลูกค้าตั้งแต่ 2 เครื่องขึ้นไป ระบบจะยกระดับความเสี่ยงขึ้นเป็น **"น่าสงสัยมาก"** อัตโนมัติ
   - ทำงานแบบ Local 100% ออฟไลน์ ไม่มีการส่งข้อมูลออกนอกเครื่องร้าน

4. **แยก Demo Mode ออกจากฐานข้อมูลจริง:**
   - มีโหมดจำลองเครื่องเสมือน (Demo Mode) ให้ทดลองฟังก์ชันทั้งหมดได้แม้ไม่มีมือถือจริงเสียบอยู่
   - ข้อมูลของโหมด Demo จะถูกแยกไปบันทึกที่ `data/demo_shop.db` ไม่ปนกับสถิติจริงของร้าน พร้อมแสดงป้าย `[ 🟡 DEMO MODE ]` เด่นชัดตลอดเวลา

5. **ใบรายงานผลบริการ (Service Report):**
   - ออกใบรับรอง PDF และ HTML ให้ลูกค้าถือกลับบ้าน ประกอบด้วย ข้อมูลเครื่อง, วันที่เวลา, สรุปผลการสแกน, รายชื่อแอปที่ถูกลบพร้อมเหตุผล และคำแนะนำการใช้งานเพื่อป้องกันการติดซ้ำ

6. **ปุ่ม "เปลี่ยนเครื่อง (Reset คิว)":**
   - เคลียร์ Cache ไอคอน, ผลการสแกน และรีเซ็ตสถานะทั้งหมดในคลิกเดียว พร้อมรับเครื่องลูกค้ารายถัดไปโดยไม่ต้องปิดเปิดโปรแกรมใหม่

7. **Zero-Network Privacy Guarantee:**
   - ไม่มี Network call, Telemetry หรือ Tracking ใดๆ ข้อมูลเครื่องและสถิติของลูกค้าจะอยู่เฉพาะในคอมพิวเตอร์ของร้านเท่านั้น

## โครงสร้างโปรเจกต์

```
ads/
├── core/
│   ├── adb.py             # จัดการ ADB, ดึงรายการแอป -3, Dumpsys, และโหมด Demo จำลอง
│   ├── analyzer.py        # ประเมินคะแนนความเสี่ยง วิเคราะห์ Permissions และ Shop Intel
│   ├── apk_parser.py      # ดึงไอคอนและชื่อแอปจาก APK พร้อมระบบ Fallback
│   ├── db.py              # SQLite จัดการประวัติเครื่อง, การเตือน 30 วัน, และ Threat Intel
│   └── report.py          # สร้างใบรายงานบริการ PDF (รองรับฟอนต์ไทย) และ HTML Slip
├── gui/
│   ├── app.py             # หน้าต่างหลัก Desktop GUI (CustomTkinter)
│   ├── components.py      # การ์ดแสดงผลแอป (AppCard) และป้ายระดับความเสี่ยง (RiskBadge)
│   └── dialogs.py         # หน้าต่างยืนยันการลบ, คู่มือถอน Device Admin, หน้าต่างดูประวัติ
├── tests/
│   ├── test_analyzer.py   # ทดสอบตรรกะการให้คะแนนความเสี่ยง
│   ├── test_db.py         # ทดสอบการเตือน 30 วัน และความฉลาดของ Threat Intel
│   ├── test_gui_flow.py   # ทดสอบกระบวนการทำงานแบบ End-to-End
│   └── test_network.py    # ทดสอบการันตี Zero-Network (ห้ามมีการต่อเน็ต)
├── reports/               # โฟลเดอร์เก็บไฟล์ PDF / HTML ใบรายงานบริการ
├── cache/icons/           # โฟลเดอร์แคชไอคอนแอป
├── main.py                # จุดรันโปรแกรมหลัก
├── requirements.txt       # รายการ Library ที่จำเป็น
└── build_exe.py           # สคริปต์คอมไพล์เป็นไฟล์เดียวผ่าน PyInstaller
```

## วิธีการติดตั้งและรันใช้งาน

### 1. ติดตั้ง Dependencies (สร้าง Virtual Environment)
```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

### 2. รันโปรแกรมหน้าร้าน
```bash
.venv/bin/python main.py
```

### 3. รัน Unit Tests ทั้งหมด
```bash
.venv/bin/pytest -v
```

### 4. แพ็กเกจเป็นไฟล์ Executable (.app / .exe)
```bash
.venv/bin/python build_exe.py
```

## ขั้นตอนการทำงานจริงหน้าร้าน (Technician Workflow)

1. **เปิดโปรแกรม:** ค่าเริ่มต้นจะแสดงหน้าจอทำงานพร้อมใช้งานทันที
2. **เสียบสายมือถือลูกค้า:**
   - เปิด "การแก้ไขข้อบกพร่อง USB" (USB Debugging) บนเครื่อง Android
   - เลือกรุ่น/Serial จากเมนูดรอปดาวน์ด้านบน (หากเสียบพร้อมกันหลายเครื่อง)
   - หากเป็นเครื่องที่เคยมาซ้ำใน 30 วัน จะมีแถบเตือนสีส้มขึ้นทันที
3. **กด "🔍 สแกนแอปทั้งหมด":**
   - โปรแกรมจะแสดงรายชื่อแอปทั้งหมดพร้อมไอคอนและระดับความเสี่ยง
4. **เลือกแอปที่ต้องการลบ:**
   - กดปุ่มด่วน **"⚡ เลือกทั้งหมดที่มีความเสี่ยงสูง"** เพื่อติ๊กเฉพาะแอปสีแดงทันที หรือติ๊กเลือกด้วยตนเอง
5. **หากมีแอปที่เป็น Device Admin:**
   - กดปุ่ม **"🛡️ ถอนสิทธิ์ Device Admin"** ก่อน (หากติดระบบป้องกันของ Android โปรแกรมจะมีหน้าต่างบอกขั้นตอนให้ช่างปิดสิทธิ์ใน Settings มือถือ)
6. **กด "🗑️ ลบแอปที่เลือก":**
   - ตรวจสอบรายการในหน้าต่าง Confirm ยืนยัน แล้วกด "ยืนยันการลบ"
7. **กด "🔄 สแกนซ้ำ":**
   - ตรวจสอบให้แน่ใจว่าเครื่องสะอาดเรียบร้อยก่อนส่งมอบ
8. **กด "📄 ใบรายงานบริการ (PDF)":**
   - พิมพ์ใบรายงานผล หรือส่งเป็น PDF ให้ลูกค้าไว้เป็นหลักฐาน
9. **กด "👥 เปลี่ยนเครื่อง (Reset คิว)":**
   - เคลียร์หน้าจอพร้อมรับเครื่องลูกค้ารายต่อไปได้ทันที
